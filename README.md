🎧 Spotify Web Player UI Clone

A responsive Spotify Web Player UI clone built using HTML5 and CSS3.
This project recreates the look and feel of the official Spotify web interface, focusing on layout, styling, and responsiveness.

📌 Features

🎵 Sidebar navigation (Home, Search, Library)

📚 Playlist and podcast suggestion cards

🔥 Trending & Recently Played sections

🎛️ Sticky top navigation bar

⏯️ Music player layout with controls and progress bar

📱 Basic responsive behavior (icons hidden on smaller screens)

🎨 Clean dark theme inspired by Spotify

🛠️ Built With

HTML5 — Structure and layout

CSS3 — Styling and responsiveness

Font Awesome — Icons

Google Fonts (Montserrat & Poppins) — Typography
